## Final regression result

The combined final run found actual letter reordering during rapid typing while focus decorations were being dispatched. Fixed it by fencing cosmetic measurements during native `beforeinput`/`input`, waiting for the input processing task to finish, and checking that native DOM selection mapped through public CodeMirror APIs agrees with editor state before changing decoration DOM. No private observer hooks or document rewriting are used.

Typecheck and editor lint pass after the correction. Native Safari and OS IME remain unverified.
